# Matrix core — генератор эмблемы ступицы

`index.html` — самодостаточная страница (HTML + JS, без сборки), которая процедурно рисует на canvas 2D три
варианта эмблемы для центра колеса темы «Матрица», каждый 512×512, всё за пределами вписанной окружности —
чистый чёрный (ступица в приложении — круг 20 % колеса, `border-radius: 100%`, `background-size: cover`):

- `#rain` — диск цифрового дождя: ~45 колонок полуширинной катаканы и цифр, длинные затухающие хвосты, яркие
  бело-зелёные головы со свечением, зелёная дымка, фосфорное кольцо у края, виньетка;
- `#wordmark` — тот же дождь, приглушённый до 55 %, плюс слово MATRIX шрифтом «Matrix Title» (~78 % ширины
  диска) с многослойным зелёным свечением и лёгкими CRT-скан-линиями;
- `#pills` — приглушённый дождь плюс скрещённые красная и синяя капсулы.

Дождь генерируется PRNG mulberry32 с фиксированным зерном, поэтому картинки воспроизводимы. Шрифт
`public/fonts/matrix/matrix.ttf` вшит в страницу как base64 data URL (`@font-face`, семейство «Matrix Title»),
рисование начинается после `document.fonts.ready`. Под канвасами есть превью 150 px в масштабе ступицы.

## Как перерендерить

1. Открыть `tools/matrix-core/index.html` в Chromium-браузере (двойным кликом или через любой статический сервер,
   например `node -e` с `http.createServer` на свободном порту — Vite для этого не нужен).
2. В консоли: `document.getElementById('wordmark').toDataURL('image/png')`, скопировать строку и декодировать:
   `node -e "require('fs').writeFileSync('core.png', Buffer.from(process.argv[1].split('base64,')[1], 'base64'))" "<строка>"`.
   Либо правой кнопкой по канвасу → «Сохранить изображение как…».
3. Положить результат в `public/themes/matrix/core.png` (путь прописан в `parts.coreImage` темы).

Если менялся `matrix.ttf`, заново вшить шрифт: заменить содержимое `base64,…)` в `@font-face` на
`node -e "console.log(require('fs').readFileSync('public/fonts/matrix/matrix.ttf').toString('base64'))"`.

## Что используется сейчас

`public/themes/matrix/core.png` — вариант `#pills` (выбор команды 2026-09-16: красная и синяя капсулы — самая
узнаваемая отсылка к фильму, а контрастная пара цветов хорошо видна на 150 px). `#wordmark` со словом MATRIX
фирменным шрифтом и `#rain` остаются в генераторе как запасные варианты.
