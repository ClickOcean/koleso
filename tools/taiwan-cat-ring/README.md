# Taiwan cat ring — сборка обода с котятами

`compose.py` собирает `public/themes/taiwan/cat-ring.webp`: тонкий красный лаковый обод с золотой линией со
стороны секторов и 54 спящих котёнка на нём. Внешнего бортика нет специально: в сгенерированных целиком
концептах котики лежали в жёлобе между двумя золотыми стенками и выглядели придавленными, «в клетке».
Генератор не держит заданную ширину кольца (просили 10 % радиуса — получали 18–20 %), поэтому кольцо собирается
из отдельных котят, а ширина и число задаются точно.

`kittens/` — 32 котёнка клубочком, вид сверху, прозрачный фон, до 256 px. Вырезаны из двух листов 4×4,
сгенерированных в Higgsfield (Seedream 5.0 Pro, `--remove_bg true`), по связным областям альфы; край альфы
подрезан на 1 px, чтобы не было светлого ореола от вырезки фона.

## Как пересобрать

```
python tools/taiwan-cat-ring/compose.py
```

Нужны Python 3, Pillow и numpy. Параметры — константы в начале скрипта: где начинается обод (`INNER`), сколько
котят (`COUNT`), их размер (`KITTEN`) и радиус (`KITTEN_RADIUS`), зерно раскладки (`SEED`). Картинка покрывает
`EXTENT` = 1.03 радиуса, чтобы котята могли чуть выглядывать за край колеса; скрипт печатает, докуда дотянулся
самый дальний пиксель. Держите его в пределах ~1.01 R: под колесом до бегущей строки остаётся всего ~6 px.

Если меняются `INNER` или `EXTENT`, поправьте `CAT_RING_INNER` и `CAT_RING_EXTENT` в `taiwanTokens.ts`, а вслед
за ними `LABEL_OUTER` (конец имён, чуть внутри обода) и `INLAY_INNER` (полоска цвета участника под ободом).
